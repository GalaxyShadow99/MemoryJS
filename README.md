# Jeu de Memory en Vanilla JS

> Application web interactive d'un jeu de Memory développée dans le cadre de la ressource R3.01 (Développement Web) au BUT Informatique de l'IUT de Caen.

**Déploiement GitHub Pages :** [https://GalaxyShadow99.github.io/MemoryJS/](https://GalaxyShadow99.github.io/MemoryJS/) *(remplacer par votre lien final)*

---

## Fonctionnalités

* **Fetch en JS :** Récupération d'images uniques via l'API [Lorem Picsum](https://picsum.photos/) et mélange des cartes avec l'algorithme de **Fisher-Yates**.
* **Logique de jeu & Asynchronisme :** Gestion des tours avec sécurité (anti-double-clic, cartes déjà trouvées, verrouillage du plateau) et temporisation asynchrone pour la vérification des paires.
* **Chronomètre & Compteur de coups :** Suivi en temps réel des performances du joueur.

---

## Technologies utilisées

* **HTML5** (Structure sémantique & A11y)
* **CSS3 & Bootstrap 5** (CSS Grid, Flexbox et styles réactifs)
* **JavaScript** (DOM manipulation, Asynchronisme, Fisher-Yates)

## Lancement en local

1. **Cloner le dépôt :**
   ```bash
   git clone https://github.com/GalaxyShadow99/MemoryJS.git
   cd MemoryJS
   ```

2. **Ouvrir le projet :**
   * Lancez le fichier `index.html` directement dans votre navigateur.
   * *Optionnel :* Utilisez l'extension **Live Server** sous VS Code.
